# Kassa

Twelve wordt gebruikt voor de kassa en betalingen in de kantine.

Twelve richt zijn kassasysteem specifiek ook op sportclubs en ondersteunt naast de kassa onder andere betaaloplossingen en rapportages.

Indeling prijs scherm :
https://admin.twelve.eu/scripts/admin/product/productgroup_edit.aspx?clt_id=336&strTab=prg

`KassaSchermen_0_{groepnaam}`
`KassaSchermen_1_FRISDRANKEN`

Hier word de naam per groep gezet

In de groep werden mapen gemaakt met

`0_{producten naam}`
`1_AA oranje / wit / groen`

In deze map zitten de producten zo dat de juiste prijs kan worden laten zien.
